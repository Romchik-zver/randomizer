+ **Случайное число** в диапазоне: Минимум/максимум, целое/дробное. 

Механика: Math.random() * (max - min) + min.

+ **Монетка** (Орёл/Решка): С анимацией подбрасывания и вращения.

Механика: Рендеринг 3D-монеты через CSS transform и rotateY, остановка на случайной стороне.

+ **Кубик (Dice)**: Один или несколько кубиков (d4, d6, d8, d10, d12, d20). С анимацией броска.

Механика: Для каждого кубика — Math.floor(Math.random() * N) + 1. Анимация — быстрая смена чисел/граней с замедлением.

+ **Колесо Фортуны (Рулетка)**: Секторы с разным весом (вероятностью).

Механика: Массив объектов {label, weight}, вычисление общей суммы, выбор случайного числа в этом диапазоне и определение попадания в сектор. Сложная часть — плавная анимация вращения с замедлением по инерции.

+ **Случайная карта из колоды**: Вытянуть одну или несколько карт из стандартной колоды в 52/54 карты.

Механика: Массив строк ['2♠', '2♥', ... 'A♦']. splice(randomIndex, 1) для вытягивания без повторений.

+ **Случайный цвет (HEX/RGB)**: Генерация и отображение цвета.

Механика: '#' + Math.floor(Math.random()*16777215).toString(16).padStart(6, '0').

+ **Случайный выбор из списка**: Ввод списка элементов (через запятую или с новой строки). Выбор одного или нескольких.

Механика: split() строки в массив, выбор случайного индекса.

# Категория 3: Генераторы контента и вдохновения

+ **Генератор случайных идей для проекта/рисунка/статьи**: Комбинация "Объект" + "Действие" + "Место" ("Робот", "Ищет", "В старом замке").

Механика: Три массива слов, случайный элемент из каждого.

+ **Генератор имени/ника/названия**: Слоговый или из списка прилагательных+существительных ("Безмятежный Остролист").

Механика: Конкатенация случайных элементов из массивов слогов или слов.

+ **Генератор случайного палитры цветов (Color Palette)**: 3-5 гармоничных случайных цветов.

Механика: Генерация базового цвета в HSL, затем добавление к его Hue значений +30, +60, +180 градусов (аналоговая, триадная, комплементарная схемы).

+ **Генератор случайного градиента**: Два случайных цвета и направление.

Случайная цитата/факт: Загрузка из локального JSON или публичного API (например, Advice Slip).

+ **Генератор мелодии/ритма (очень упрощённо)**: Случайная последовательность нот (A, B, C...) или битов (x - хлопок, . - пауза).

Механика: Массив символов, генерация строки, воспроизведение через Web Audio API с разной частотой или заранее записанными звуками.
